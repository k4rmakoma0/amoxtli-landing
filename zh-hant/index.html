Markdown，本該如此

Amoxtli 是適用於 Mac、Windows 和 Linux 的原生 Markdown 檢視器。打開檔案或整個檔案夾，無須任何設定，即可閱讀排版良好的內容。

下載 Mac 版 下載 Windows 版 下載 Linux 版

macOS 27 · Windows 10（1809）或更新版本 · Linux x86_64 (Flatpak).

瀏覽整個筆記檔案夾

打開檔案夾即可查看其中的 Markdown 檔案，包括子檔案夾中的檔案，並依檔案夾分組。選擇一個檔案即可開始閱讀。

打開連結前查看其去向

將指標停留在連結上可查看完整 URL。在打開不熟悉的網站前，或連結文字與實際目標不是同一網站時，Amoxtli 會發出警告。

  • 目錄

    根據文件標題產生。按一下項目即可前往該部分。

  • 井然有序

    支援巢狀列表、引言、程式碼區塊、表格、刪除線和遠端圖片。

  • 淺色和深色

    跟隨系統外觀和你的強調色。

  • 唯讀

    Amoxtli 絕不會更改你的檔案，可以放心打開任何內容。

  • 重視隱私

    沒有帳號、廣告或追蹤。僅在載入文件中的圖片時連線。

  • 使用你的語言

    支援多種語言，並在 Mac 上支援 VoiceOver。

取得 Amoxtli

免費開源，適用於 Mac、Windows 和 Linux。

Microsoft Store · Windows

透過 Microsoft Store 安裝和更新 Windows App。

從 Microsoft Store 取得

Homebrew · Mac

透過終端機安裝和更新。

brew install --cask k4rmakoma0/tap/amoxtli

直接下載 · Mac

來自 GitHub Releases 的已公證 App。解壓縮後移到「應用程式」檔案夾。

下載 ZIP在 GitHub 上查看版本

Flatpak · Linux

適用於已安裝 Flatpak 的 x86_64 Linux。請在此下載新版本以更新 App。

下載 Flatpak
flatpak install --user amoxtli-1.1.0-x86_64.flatpak
在 GitHub 上查看版本

Mac App Store

即將推出。

Snap Store · Linux

從 Snap Store 安裝及更新 Linux 應用程式。

從 Snap Store 取得
sudo snap install amoxtli
