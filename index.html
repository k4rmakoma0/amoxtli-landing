Free and open source, for Mac, Windows and Linux

Markdown, the way it should look

Amoxtli is a native Markdown viewer for Mac, Windows and Linux. Open a file or a whole folder and read it properly formatted, with nothing to set up.

Download for Mac Download for Windows Download for Linux

macOS 27 · Windows 10 (1809) or later · Linux x86_64 (Flatpak).

Browse a whole folder of notes

Open a folder to see its Markdown files, including those in subfolders, grouped by folder. Pick one and start reading.

See where a link goes before you open it

Hover over a link to see its full URL. Amoxtli warns you before it opens an unfamiliar site, or when a link’s text names a different site from the one it goes to.

  • Table of contents

    Built from the document’s headings. Click an entry to jump to that section.

  • Everything in its place

    Nested lists, quotes, code blocks, tables, strikethrough, and remote images.

  • Light and dark

    Follows your system appearance and your accent color.

  • Read-only

    Amoxtli never changes your files, so you can open anything without worry.

  • Private

    No accounts, ads, or tracking. It only goes online to load images in your documents.

  • In your language

    Available in multiple languages, with VoiceOver support on Mac.
