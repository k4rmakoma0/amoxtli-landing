Markdown, como deve ser

O Amoxtli é um visualizador de Markdown nativo para Mac, Windows e Linux. Abra um arquivo ou uma pasta inteira e leia com boa formatação, sem configurar nada.

Baixar para Mac Baixar para Windows Baixar para Linux

macOS 27 · Windows 10 (1809) ou posterior · Linux x86_64 (Flatpak).

Explore uma pasta inteira de notas

Abra uma pasta para ver os arquivos Markdown dela, inclusive os de subpastas, agrupados por pasta. Escolha um e comece a ler.

Veja para onde um link leva antes de abri-lo

Passe o cursor sobre um link para ver a URL completa. O Amoxtli avisa antes de abrir um site desconhecido, ou quando o texto de um link cita um site diferente do destino.

  • Índice

    Criado a partir dos títulos do documento. Clique em um item para ir à seção.

  • Tudo no lugar

    Listas aninhadas, citações, blocos de código, tabelas, texto riscado e imagens remotas.

  • Claro e escuro

    Segue a aparência do sistema e a sua cor de destaque.

  • Somente leitura

    O Amoxtli nunca altera seus arquivos, então você pode abrir o que quiser sem preocupação.

  • Privado

    Sem contas, anúncios ou rastreamento. Só se conecta para carregar imagens dos seus documentos.

  • No seu idioma

    Disponível em vários idiomas e compatível com o VoiceOver no Mac.
