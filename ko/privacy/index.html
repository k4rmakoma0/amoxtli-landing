개인정보 처리방침

시행일: 2026년 11월 1일

이 번역은 편의를 위해 제공됩니다. 내용이 다를 경우 영어 버전이 우선합니다.

Amoxtli: Markdown Viewer(‘Amoxtli’)는 Mac용 읽기 전용 Markdown 뷰어입니다. Amoxtli는 개인 데이터를 수집하지 않으며, 서버에 저장하거나 판매하거나 공유하지 않습니다. 계정, 광고, 분석, 추적이 없으며 개발자는 앱 사용에 관한 어떠한 정보도 받지 않습니다.

문서

사용자가 여는 파일과 폴더는 Mac에서 읽히며 개발자에게 전송되지 않습니다. Amoxtli는 이를 변경하지 않습니다.

Mac에 보관되는 데이터

Amoxtli는 정상적으로 작동하기 위해 Mac의 전용 저장 공간에 일부 정보를 보관합니다.

  • 링크를 열 때 항상 신뢰하기로 선택한 사이트
  • Amoxtli를 기본 뷰어로 사용할지 다시 묻지 않기로 한 선택
  • 윈도우를 복원하기 위한 윈도우 상태 및 열었던 폴더의 접근 권한
  • 시스템이 임시 캐시에 보관할 수 있는 문서의 이미지

신뢰하는 사이트는 앱 메뉴의 ‘신뢰하는 사이트 지우기’로 지울 수 있습니다. 나머지는 앱을 제거하고 데이터를 삭제하면 지워집니다.

다른 서비스와의 연결

Amoxtli는 사용자가 연 문서의 원격 이미지를 불러올 때만 인터넷에 연결합니다. 이때 Mac은 이미지를 호스팅하는 서버에 연결하며, 해당 서버는 IP 주소와 요청 시간 같은 정보를 볼 수 있습니다. 이러한 서버는 각 문서의 작성자가 선택하며 개발자가 관리하지 않습니다.

링크는 사용자가 열기로 선택한 경우에만 브라우저나 다른 앱에서 열립니다. 해당 사이트와 앱에는 각자의 개인정보 처리방침이 있습니다.

앱 배포

Mac App Store, GitHub 또는 Homebrew에서 Amoxtli를 다운로드하는 경우 해당 서비스는 자체 개인정보 처리방침에 따라 데이터를 처리할 수 있습니다. 개발자는 다운로드 수와, 개발자와 공유하는 데 동의한 경우의 충돌 보고서 등 Apple이 제공하는 집계 통계를 볼 수 있습니다.

아동

Amoxtli는 아동을 포함하여 누구의 데이터도 고의로 수집하지 않습니다.

변경 사항

이 방침의 변경 사항은 새로운 시행일과 함께 이 페이지에 게시됩니다.
