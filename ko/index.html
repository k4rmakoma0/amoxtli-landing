무료 오픈 소스, Mac, Windows 및 Linux용

Markdown을 있어야 할 모습 그대로

Amoxtli는 Mac, Windows 및 Linux용 네이티브 Markdown 뷰어입니다. 파일이나 폴더 전체를 열면 별도의 설정 없이 보기 좋은 형식으로 읽을 수 있습니다.

Mac용 다운로드 Windows용 다운로드 Linux용 다운로드

macOS 27 · Windows 10 (1809) 이상 · Linux x86_64 (Flatpak).

노트 폴더 전체 둘러보기

폴더를 열면 하위 폴더를 포함한 Markdown 파일이 폴더별로 표시됩니다. 파일을 선택하고 읽기 시작하십시오.

링크를 열기 전에 연결되는 위치 확인

링크 위에 포인터를 올리면 전체 URL이 표시됩니다. 알 수 없는 사이트를 열기 전이나 링크 텍스트가 실제 대상과 다른 사이트를 가리킬 때 Amoxtli가 경고합니다.

  • 목차

    문서의 제목으로 생성됩니다. 항목을 클릭하면 해당 섹션으로 이동합니다.

  • 모든 요소를 제자리에

    중첩 목록, 인용문, 코드 블록, 표, 취소선, 원격 이미지를 지원합니다.

  • 라이트 및 다크

    시스템 화면 모드와 강조 색상을 따릅니다.

  • 읽기 전용

    Amoxtli는 파일을 변경하지 않으므로 안심하고 열 수 있습니다.

  • 개인정보 보호

    계정, 광고, 추적이 없습니다. 문서의 이미지를 불러올 때만 연결합니다.

  • 사용자의 언어로

    여러 언어로 제공되며 Mac에서 VoiceOver를 지원합니다.
