免费开源，适用于 Mac

Markdown，本该如此

Amoxtli 是适用于 Mac 的原生 Markdown 查看器。打开文件或整个文件夹，无需任何设置，即可阅读排版良好的内容。

下载 Mac 版
brew install --cask k4rmakoma0/tap/amoxtli

需要 macOS 27。

浏览整个笔记文件夹

打开文件夹即可查看其中的 Markdown 文件，包括子文件夹中的文件，并按文件夹分组。选择一个文件即可开始阅读。

打开链接前查看其去向

将指针悬停在链接上可查看完整 URL。在打开陌生网站前，或链接文字与实际目标不是同一网站时，Amoxtli 会发出警告。

  • 目录

    根据文档标题生成。点按条目即可前往相应部分。

  • 井然有序

    支持嵌套列表、引用、代码块、表格、删除线和远程图片。

  • 浅色和深色

    跟随系统外观和你的强调色。

  • 只读

    Amoxtli 绝不会更改你的文件，可以放心打开任何内容。

  • 注重隐私

    没有账户、广告或跟踪。仅在加载文档中的图片时联网。

  • 使用你的语言

    提供 11 种语言，并支持旁白。

获取 Amoxtli
