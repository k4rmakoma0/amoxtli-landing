無料のオープンソース、Mac・Windows・Linux向け

Markdownを、あるべき姿で

Amoxtliは、Mac・Windows・Linux向けのネイティブなMarkdownビューアです。ファイルやフォルダ全体を開くだけで、設定なしで整った表示のまま読めます。

Mac版をダウンロード Windows版をダウンロード Linux版をダウンロード

macOS 27 · Windows 10（1809）以降 · Linux x86_64 (Flatpak).

ノートのフォルダ全体をブラウズ

フォルダを開くと、サブフォルダを含むMarkdownファイルがフォルダごとに表示されます。ファイルを選ぶだけで読み始められます。

リンク先を開く前に確認

リンクにポインタを合わせると完全なURLを表示します。不明なサイトを開く前や、リンクのテキストが実際とは別のサイトを示している場合には警告します。

  • 目次

    書類の見出しから作成します。項目をクリックすると該当セクションへ移動します。

  • すべてをきれいに

    入れ子のリスト、引用、コードブロック、表、取り消し線、リモート画像に対応。

  • ライトとダーク

    システムの外観とアクセントカラーに従います。

  • 読み取り専用

    Amoxtliがファイルを変更することはないので、安心して開けます。

  • プライバシー

    アカウント、広告、トラッキングはありません。書類の画像を読み込むときだけ接続します。

  • あなたの言語で

    複数の言語に対応し、MacではVoiceOverにも対応しています。

Amoxtliを入手

Mac・Windows・Linux向けの無料オープンソースアプリ。

Microsoft Store · Windows

Windows版はMicrosoft Storeからインストールとアップデートができます。

Microsoft Storeで入手

Homebrew · Mac

ターミナルからインストールとアップデートができます。

brew install --cask k4rmakoma0/tap/amoxtli

直接ダウンロード · Mac

GitHub Releasesの公証済みアプリです。解凍して「アプリケーション」に移動してください。

ZIPをダウンロードGitHubでバージョンを見る

Flatpak · Linux

Flatpakを利用するx86_64 Linux向け。更新するには、ここから新しいバージョンをダウンロードしてください。

Flatpakをダウンロード
flatpak install --user amoxtli-1.1.0-x86_64.flatpak
GitHubでバージョンを見る
