Бесплатно и с открытым кодом, для Mac, Windows и Linux

Markdown таким, каким он должен быть

Amoxtli — нативное приложение для просмотра Markdown на Mac, Windows и Linux. Откройте файл или целую папку и читайте с правильным форматированием, без настройки.

Загрузить для Mac Скачать для Windows Скачать для Linux

macOS 27 · Windows 10 (1809) или новее · Linux x86_64 (Flatpak).

Просматривайте целую папку заметок

Откройте папку, чтобы увидеть ее файлы Markdown, включая файлы во вложенных папках, сгруппированные по папкам. Выберите файл и начните читать.

Смотрите, куда ведет ссылка, прежде чем открыть ее

Наведите указатель на ссылку, чтобы увидеть полный URL. Amoxtli предупредит вас перед открытием незнакомого сайта или если текст ссылки называет не тот сайт, на который она ведет.

  • Содержание

    Создается на основе заголовков документа. Нажмите на пункт, чтобы перейти к разделу.

  • Всё на своем месте

    Вложенные списки, цитаты, блоки кода, таблицы, зачеркнутый текст и изображения из сети.

  • Светлое и темное

    Следует оформлению системы и вашему цвету акцента.

  • Только чтение

    Amoxtli никогда не изменяет ваши файлы, поэтому можно открывать что угодно без опасений.

  • Конфиденциально

    Без учетных записей, рекламы и отслеживания. В сеть выходит только для загрузки изображений из документов.

  • На вашем языке

    Доступно на нескольких языках, с поддержкой VoiceOver на Mac.

Homebrew · Mac

Устанавливайте и обновляйте через Терминал.

brew install --cask k4rmakoma0/tap/amoxtli

Прямая загрузка · Mac
