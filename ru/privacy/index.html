Политика конфиденциальности

Действует с 1 ноября 2026 г.

Этот перевод предоставлен для удобства. При расхождениях преимущество имеет английская версия.

Amoxtli: Markdown Viewer («Amoxtli») — приложение для просмотра Markdown на Mac, только для чтения. Amoxtli не собирает ваши личные данные, не хранит их на серверах, не продает и не передает их. В нем нет учетных записей, рекламы, аналитики и отслеживания, а разработчик не получает никаких данных о том, как вы пользуетесь приложением.

Ваши документы

Открытые вами файлы и папки считываются на вашем Mac и никогда не отправляются разработчику. Amoxtli никогда их не изменяет.

Данные на вашем Mac

Для правильной работы Amoxtli хранит некоторые данные в своем личном хранилище на вашем Mac:

  • Сайты, которым вы решили всегда доверять при открытии ссылок
  • Ваш выбор больше не спрашивать о назначении Amoxtli приложением по умолчанию
  • Состояние окон и разрешения на доступ к открытым папкам, чтобы эти окна можно было восстановить
  • Изображения из документов, которые система может хранить во временном кэше

Надежные сайты можно удалить командой «Забыть надежные сайты» в меню приложения. Остальное удаляется при удалении приложения и его данных.

Подключения к другим службам

Amoxtli подключается к интернету только для загрузки изображений из сети, которые есть в открытых вами документах. При этом ваш Mac обращается к серверу с изображением, и этот сервер может видеть такие сведения, как ваш IP-адрес и время запроса. Эти серверы выбирает автор документа, и разработчик их не контролирует.

Ссылки открываются в браузере или другом приложении только тогда, когда вы решите их открыть. У этих сайтов и приложений свои политики конфиденциальности.

Распространение приложения

Если вы загружаете Amoxtli из Mac App Store, с GitHub или через Homebrew, эти службы могут обрабатывать данные в соответствии со своими политиками конфиденциальности. Разработчик может видеть обобщенную статистику от Apple, например число загрузок и, если вы согласились передавать их разработчикам, отчеты о сбоях.

Дети

Amoxtli намеренно не собирает данные ни о ком, в том числе о детях.

Изменения

Любые изменения этой политики будут опубликованы на этой странице с новой датой вступления в силу.

Контакты

С вопросами об этой политике создайте issue на GitHub. Issues общедоступны, поэтому не указывайте личные данные.
